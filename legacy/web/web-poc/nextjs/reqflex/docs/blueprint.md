# **App Name**: ReqFlex

## Core Features:

- Requirement List: Display a list of all requirements, fetched from the Go API, with key details visible (name, status, technologies).
- Requirement Details: Show a detailed view of a single requirement, including all fields (name, description, status, technologies, sub-items, dates).
- Requirement Creation: Allow users to create new requirements via a form, submitting data to the Go API.
- Requirement Editing: Enable users to edit existing requirements, updating the Go API.
- Requirement Deletion: Allow users to delete requirements, triggering deletion in the Go API.
- Status-Based Filtering: Implement filtering of requirements based on their status (pending, in-progress, complete).
- Sub-item Management: Enable users to add, edit, and delete sub-items within a requirement.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5) to evoke a sense of professionalism and organization.
- Background color: Light grey (#F0F0F3) for a clean and modern look.
- Accent color: Teal (#009688) to provide contrast and highlight important actions and status indicators.
- Body and headline font: 'Inter' sans-serif font for a clean, modern, neutral aesthetic.
- Use a consistent set of minimalist icons from a library like Material Design Icons to represent requirement status and actions.
- Employ a clean, card-based layout for displaying requirements, ensuring easy readability and scannability.
- Subtle transitions and animations on interactions (e.g., hovering, clicking) to provide feedback and enhance the user experience.
