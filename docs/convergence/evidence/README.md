# Convergence evidence — plan 8261645

Evidence produced by the bounded rehearsal (`bin/convergence_rehearsal.py`) and the
seed gate (`bin/convergence_seed_gate.py`). Every file here is generated by a run;
none is hand-written. Regenerate both rather than editing them:

```bash
python3 bin/convergence_rehearsal.py   # writes b1 + b2 and re-runs the seed gate
python3 bin/convergence_seed_gate.py   # writes d3 alone (read-only)
```

Scope: the rehearsal drives a gateway that stands in for conduit-mcp on an ephemeral
loopback port, persists the accepted chain only in a throwaway PostgreSQL database
inside a transaction that is rolled back, and proves zero live receipts for those ids.
It supersedes nothing, seeds nothing, merges nothing and approves nothing.
