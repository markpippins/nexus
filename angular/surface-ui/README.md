# Widget Weaver

I need a widget catalog application. I need to be able to paste in a react component that talks to a back-end REST API, convert the API to a source of mock data to animate the widget while it is in the catalog, and a matching function to locate other widgets that have the same input scheme while specifically sharing the same REST API.
